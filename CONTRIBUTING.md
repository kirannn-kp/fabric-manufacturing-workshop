# Contributing

- Keep changes in the private workshop repository. Do not submit to public MOAW.
- Use short sentences, actual UI labels, numbered steps, expected results, and recovery steps. Rehearse as a participant, not only as an administrator.
- Keep all data invented. If a data change alters a metric, update the validation summary, report instructions, and answer key together.
- Use relative links. Review Microsoft Learn when changing click paths. Attribute upstream patterns without importing upstream prose, screenshots, or setup tooling.
- Use only approved screenshots captured in a demo workspace. Remove identifiers and secrets before adding them. Keep text placeholders until authentic captures exist.
