# Security

Use only the supplied synthetic data. Never commit or upload real operational data, personal data, credentials, tenant IDs, or private URLs. Do not enable public sharing or Publish to web.

Report a suspected issue directly to the facilitator or the organizer's private security contact. Include the affected item, time and time zone, a redacted description, and how to reach you. Do not include secrets or open a public issue. If data or credentials were exposed, also follow your organization's incident process.
