# Manufacturing Operations with Microsoft Fabric

Which production orders need attention this morning? Use seven synthetic CSV files to answer that question in the Microsoft Fabric browser interface. No real operational data is included.

**Participants:** Start at [workshop.md](workshop.md). Download the workshop files, check [prerequisites](docs/00-prerequisites.md), and join your assigned Fabric workspace. Day 1 and Day 2 are the core workshop; Day 3 is for PoC planning with an optional Foundry demonstration. GitHub is for access to the materials, not for coding. No Copilot, VS Code, Power BI Desktop, notebook, or Microsoft Foundry access is required.

**Facilitators:** Start with the [guide](facilitator/README.md), build the starter items using [environment setup](facilitator/environment-setup.md), and use the [answer key](facilitator/answer-key.md) at checkpoints. The starter model and reports must be prepared in Fabric before Day 1; there are no binary imports in this package.
